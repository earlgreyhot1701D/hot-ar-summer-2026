3 Methodology Behind the curtain.

How it decides.

  1. Deterministic. The same idea always returns the same name. No randomness.
  2. It scans your sentence for signal words, matches an archetype, then a reproducible hash picks the figure from that archetype's shortlist.
  3. Roughly one idea in twelve trips a wild card on purpose. Also deterministic, so the same idea trips it every time.
  4. What it is not: not a trademark search, not an availability check, not the whole pantheon. A small curated table of names, offered as suggestions.
